# DSA Repository

A structured repository for Data Structures and Algorithms practice, tracking, and revision.

## Status Overview

Use the sections below to classify each file or topic by progress and clarity.

### Green - Completed / Verified
Use this section for files or topics that are fully understood, implemented correctly, and ready for revision.

- Example: `arrays/01_two_sum.py`
- Example: `sorting/merge_sort.py`
- Add completed files here as you finish them.

### Yellow - In Progress / Needs Review
Use this section for files or topics that are partially complete, being practiced, or still need verification.

- Example: `graphs/bfs_shortest_path.py`
- Example: `dynamic_programming/knapsack.py`
- Add active or half-done work here.

### Red - Needs Attention / Blocked
Use this section for files or topics that are incomplete, incorrect, or require urgent revision.

- Example: `trees/avl_tree.py`
- Example: `hashing/longest_subarray.py`
- Add blocked or confusing topics here.

## How to Use

- Mark each file or topic under one of the three sections.
- Move items from Red to Yellow as you work on them.
- Move items from Yellow to Green after they are correct and well understood.
- Keep this file updated for quick visibility and revision planning.
